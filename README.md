# ניצוץ

אפליקציית לימוד יומית בסגנון משחק, שמלמדת לעבוד עם קלוד ולבנות בעזרת AI.

## איך פותחים

- **כאתר, בכל מחשב ובטלפון:**
  `https://ofek-98.github.io/nitzutz/`
- **בטלפון כמו אפליקציה:** פותחים את הכתובת ומוסיפים אותה למסך הבית. באייפון עושים את זה מכפתור השיתוף בספארי, ובאנדרואיד מהתפריט של כרום.
- **בלי אינטרנט:** לחיצה כפולה על `index.html` במחשב.

## סנכרון בין מכשירים

באפליקציה נכנסים לפרופיל ואז לכרטיס "סנכרון בין מכשירים". מחברים פעם אחת `token` של `GitHub` עם הרשאה ל־`Gists` בלבד, וסורקים את קוד ה־`QR` עם הטלפון.

ההתקדמות נשמרת כקובץ פרטי (`Gist`) בחשבון. הקובץ הזה לא נמצא במאגר הזה.

## מה יש כאן

- `index.html`: האפליקציה המוכנה, בקובץ אחד.
- האייקונים וקובץ ה־`manifest.webmanifest`: הם מאפשרים להתקין את האתר כאפליקציה בטלפון.
- `src/`: קוד המקור והתוכן. הקובץ `src/CONTENT_GUIDE.md` מתאר את מבנה השיעורים ואת סוגי התרגילים.
- `src/tools/build-standalone.ps1`: בונה מחדש את האתר מהמקור, ב־`Windows PowerShell`, וכותב את `index.html`, את האייקונים ואת ה־`manifest` לשורש המאגר. עם הדגל `-Desktop` הוא גם מתקין את האפליקציה במחשב, עם קיצור דרך.

## שמירה ופרטיות

- בלי סנכרון, ההתקדמות נשמרת בדפדפן של כל מכשיר בנפרד. בפרופיל יש גיבוי ושחזור.
- מפתח ה־API של קלוד הוא אופציונלי. הוא נשמר רק בדפדפן שלך, ולא נכנס למאגר.
